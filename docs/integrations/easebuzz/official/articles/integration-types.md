# Integration Types
---

Integrate your website, application, or e-commerce store with the Easebuzz Payment Gateway. Choose the integration method that best suits your business and start accepting payments from your customers.

Easebuzz payment gateway integration can be implemented on the merchant side using programming languages such as Java, PHP, Python, Django, Node.js, Dot net and other languages.
