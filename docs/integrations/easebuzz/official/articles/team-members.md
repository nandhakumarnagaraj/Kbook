# Team Members
---

- Create different users of the system from your team with different set of permissions.

- You can create the users/team members on the dashboard under **"My Team"** tab.

- System allows you to create multiple users in one go with bulk file upload feature.

- Once the users are created in the system, you have to activate the users.

- Unique login URL will be sent to the active users to login. 

- Users will be able login to use the authorized tabs as per the permissions assigned. 

> **Note:** Only active users will be able to login on the system.
