What the live app does today
  • Failed sign-in hangs forever: internals go loading:false, error:"Invalid login ID or password" while the DOM still reads “Signing in…” and role="alert" count is 0.
  • Error panels are styled as loading panels (class="panel loading") on Reports, Platform dashboard and Business settings.
  • Live Orders, Reports, Terminals and Feature flags show an error with no retry button; some have no role="alert".
  • jwt.interceptor prints network / 5xx failures to the console only — the user sees nothing.
  • Prototype fix: one state owner per surface, error always has an action, loading always clears, failures announced to screen readers, success confirmed by toast.
