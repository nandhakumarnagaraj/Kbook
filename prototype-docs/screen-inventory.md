# KhanaBook Prototype — Screen Inventory

Source folder: `C:\Users\nandh\Desktop\Prototype_Images` (originals untouched; readable JPEG/PNG previews generated under `%TEMP%\kb-preview\previews`).
References are 1536×1024 PNG. Inventory order = folder order (AdminLogin, then OwnerLogin).

Design summary (from collective inspection):

- Both consoles share a dark-violet gradient sidebar (~232px) with: KhanaBook brand header + collapse chevron, uppercase group headings (Admin: PLATFORM/… ; Owner: OVERVIEW/OPERATIONS/FINANCE/BUSINESS/HELP), icon+label links, active link = bright violet pill, user footer card + Sign out.
- Content canvas is near-white; headings bold ink; subtitles muted; top-right contextual controls (date pickers, filters, primary CTA).
- Primary CTA color: orange (save/export/close on Owner; some Admin screens use violet). Output-specific action colors vary per screen — status colors: green=active/online/completed/solved, red=out-of-stock/offline/cancelled/open, orange=low-stock/pending, blue=info, violet=primary accents.
- KPI cards: white rounded cards with colored icon chips (violet/green/red/orange), big figure, muted caption.
- Tables: uppercase muted column headers, avatar/emoji rows, status pills, action icon buttons, footer pagination with orange active page.
- Tabs: underline tabs (Terminals, Reports) or chip tabs (Inventory).
