# Operations Directory

This directory contains detailed, verified operational manuals for individual cashier tasks in KhanaBook Lite POS.

Every operation adheres to the standard format:
- Operation ID (`OP-XXX`)
- Module name
- Verification status (`VERIFIED` on hardware `ZA222J5KT7`)
- Preconditions
- Navigation path
- Step-by-step instructions with actual observed behavior
- Touch coordinates / bounds
- Associated screenshots in `artifacts/android-ui-tests/`

## Index of Operations
- **`HOME_DASHBOARD_OPERATIONS.md`**: Launching bills and monitoring real-time store metrics.
- **`DINE_IN_OPERATIONS.md`**: Table selection, menu cart assembly, and table hold.
- **`PAYMENT_OPERATIONS.md`**: Multi-tender payment flows (Cash, UPI QR, POS).
- **`KOT_AND_KITCHEN_OPERATIONS.md`**: Kitchen ticket firing and reprints.
- **`ORDER_HISTORY_OPERATIONS.md`**: Daily bill logging, date filtering, and receipts.
- **`BUSINESS_SETTINGS_OPERATIONS.md`**: Overnight closing time and 30-min settlement buffer.
